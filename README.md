# Flavrtown! Clone (By hackclubber @spj)

> Test it out on [ft-clone](https://ft-clone-nu.vercel.app/)!

This is a flavortown clone, made using react+next.js for frontend and backend, tailwind css for design, supabase for database, hackatime api to track time, hackatime auth for login and hackclub cdn to store images. This was made for [macondo](https://macondo.hackclub.com). This has almost all of the features of flavortown, including

1. Using hackatime to track actual programming time
2. Creating projects and devlogs
3. shipping projects and voting on them
4. earning payouts after getting 12 votes and voting on 15 projects
5. a shipwrights dashboard (public) to approve/reject ships
6. a responsive design, that means it works well on almost every design!

## How does it work?

To use it,
1. Login using hackatime
2. Go to projects, and make a new project, and link hackatime
3. Add demo, repo and banner
4. Work on your project, and add devlogs to register that much time
5. Once you finish your project, ship it, and wait for a reviewer to approve it
6. After your project gets approved, vote on 15 other projects, and wait for 12 people to vote on your project 
7. Earn cookies, and DO NOT spend them as shop is not open.
